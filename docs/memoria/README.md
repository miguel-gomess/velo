# Memoria TFG — Velo

Estructura según la guía del centro (**10 apartados**):

1. Portada  
2. Abstract (resumen en español + abstract en inglés)  
3. Índice  
4. Justificación del proyecto  
5. Introducción  
6. Objetivos  
7. Desarrollo  
8. Conclusiones  
9. Bibliografía (APA 6)  
10. Anexos  

El texto está redactado en **lenguaje claro**, no técnico. El detalle de programación queda en el **Anexo C**.

## Regenerar el Word

```powershell
python scripts/generar-memoria-tfg.py
```

Con capturas nuevas (front y back en marcha):

```powershell
python scripts/generar-memoria-tfg.py --capturar
```

Salida: `docs/Memoria-Velo.docx`

Rellena en la portada: nombre, tutor y centro.
